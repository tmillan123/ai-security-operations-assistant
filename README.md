
# AI Security Operations Assistant

An independent AI security engineering laboratory
exploring how local Large Language Models can support
security operations and Kubernetes workload investigations.

## Objectives

- Interpret Falco runtime security alerts.
- Explain suspicious Kubernetes activity.
- Recommend investigation steps.
- Generate structured security reports.
- Evaluate AI accuracy, security and auditability.

## Technology Stack

- Python
- Ollama
- Local LLM (Qwen)
- Falco (planned integration)
- Kubernetes (kind)
- GitHub

## Current Status

Phase 1 — Initial project setup and local Ollama API
connectivity.

## Security Principles

- Human-in-the-loop investigation
- No autonomous remediation
- Untrusted alert input
- Evidence-based analysis
- No invented findings
- Local-first inference
